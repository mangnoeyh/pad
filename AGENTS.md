# Working with this kit

Apply this kit to the requested work, not unrelated tasks. Actual task instructions and the user's selected collaboration mode take precedence.

## Invariants

- Preserve authoritative instructions, raw source data and official expectations. Keep derived files in an explicit task-local output location; do not silently overwrite existing work.
- Record a rule's source separately from its enforcement. Task mandates remain protected; user-added policies may be goals, defaults or enforced conditions that the authorized user can revise. Detailed runtime policies and scoped exceptions belong to the solver's baseline-and-delivery reference.
- Use the smallest useful tools in the permitted environment. Check installed packages when relevant; do not install an entire framework for a small task.
- For tabular data, inspect identifiers, types, units, nulls, duplicates and time/group structure. Distinguish a bounded prefix from a representative sample or full data. Keep filter/join row counts and cardinality auditable; state denominators.
- For prediction, split by the real deployment boundary before preprocessing. Compare with a simple baseline and exclude future or target-derived information.
- Report only observed execution, actual decisions and verified claims. Record commands, key results, assumptions and limits. Preserve the user's real understanding/approval checkpoints; silence is neither.
- Keep task material and completed results in the task workspace. Record reused public sources by URL, version/commit, file and purpose; preserve licenses and [attribution](ATTRIBUTION.md).

The default [launch request](START_HERE.md) explicitly chooses initial understanding, two-track work, early study and user-ended improvement. Apply that mode when selected, without adding routine technical approvals or assuming it governs an unrelated direct request. Templates capture useful evidence in existing notes; they do not require extra documents or change authority.

## Controlled work environments

Follow the latest environment rules for access, execution and data transfer. Do not change managed tools/settings, bypass controls, connect external AI or personal accounts, automate a UI or transfer task material unless permitted. Reused public components must fit the real requirements and their licenses. If a later procedure restricts AI, stop drafting, editing or coaching its answers when that procedure begins; understanding practice belongs in the permitted work phase. These boundaries do not add restrictions to unrelated work.
