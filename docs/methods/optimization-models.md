# 제약을 가진 최적화 모형

여러 선택이 함께 비용·용량·시간을 바꿀 때 읽는다. 모형은 현실에서 중요한 조건을 식으로 정리한 것이다. 솔버가 푼 것은 입력한 모형이며 빠진 조건이나 잘못된 단위를 대신 발견해 준다고 가정하지 않는다. 이 문서는 방법 선택 참고자료이며 모든 방법의 실행 구현을 포함한다는 뜻은 아니다.

## 선택할 모형

| 결정할 값 | 우선 검토 | 먼저 확인할 가정 |
| --- | --- | --- |
| 나눌 수 있는 수량, 선형 비용 | LP | 분할·비례 비용이 실제로 가능한가 |
| 개수·선택 여부와 선형 관계 | MILP | 정수성, 연결 조건, 수치 범위 |
| 정수 시각·배치·조건부 논리 | CP-SAT 또는 제약계획 | 시간·수량의 정수 단위가 의미를 보존하는가 |
| 연속량의 볼록 비용 | 볼록 최적화·QP | 목적·가능 영역이 실제로 볼록인가 |
| 임의 비선형·블랙박스 비용 | 국소·전역 탐색, 시뮬레이션 최적화 | 미분·잡음·평가 비용, 보장 범위 |
| 집합이나 경로 후보의 조합 선택 | 집합 덮기·분할·시설 선택 모형 | 후보 누락이 해를 제한하는가 |

## 연속 모형

### 선형계획 LP

수량을 나누어 배분하고 비용·제약이 선형이면 먼저 검토한다. 예를 들어 여러 공급원의 물량을 처리량 한도 안에서 배분하는 문제다. `변수 수 × 제약 수`가 큰 밀집 행렬을 무조건 만들지 말고 비영 원소 수와 희소 구조를 확인한다. 내부점·심플렉스 등 실제 방법과 수치 정밀도에 따라 시간이 달라진다. 작은 예제의 꼭짓점 비교, 원래 단위의 제약 잔차, 목적 재계산으로 검산한다. [SciPy linprog](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linprog.html)

LP의 소수 해를 반올림해 분할 불가 배정으로 바꾸면 용량과 전원 처리 조건을 깨뜨릴 수 있다. LP 완화의 값은 원래 정수 최소화 문제의 하한으로 유용하지만 실행 가능한 정수 결과와 구분한다. 그림자 가격도 현재 모형·민감도 범위의 정보이지 무제한 정책 효과가 아니다.

### 볼록 QP·볼록 최적화

목표치에서 벗어난 정도를 제곱으로 벌주거나 분산을 줄일 때 검토한다. 목적 함수의 볼록성과 가능 영역을 확인해야 국소 최적성에서 전역 최적성을 논할 수 있다. 임의의 비선형 식이나 정수 선택을 넣고 같은 보장을 유지한다고 말하지 않는다. 스케일 차이·조건수·허용 오차를 확인하고 원래 문제의 잔차를 계산한다. [Boyd와 Vandenberghe의 저자 제공 교재](https://stanford.edu/~boyd/cvxbook/)

### 비선형 최적화

연속 파라미터의 복잡한 비용에는 경사법·준뉴턴·신뢰영역·도함수 없는 탐색을 검토한다. 초기값 의존, 국소해, 미분 불연속, 잡음이 주요 제약이다. 서로 다른 초기값과 간단한 탐색 기준선에서 결과를 비교하고, 종료 메시지만으로 전역 최적이라고 하지 않는다. 정수 배정 벡터를 연속 함수 API에 넣고 마지막에 반올림하는 접근은 별도 복원·검증이 없으면 유효한 배정법이 아니다.

## 정수와 논리

### 혼합정수선형계획 MILP

선택 여부를 0/1 변수로 두고 용량·비용·논리 연결을 선형 제약으로 표현한다. 예: 시설이 열렸을 때만 해당 시설로 배정하도록 `배정 ≤ 개방`을 연결한다. 변수·제약 수, 대칭, 완화의 강도, 후보 수가 성능을 좌우한다. 일반적으로 어려운 문제를 포함하므로 정해진 시간 안에 최적해를 보장하지 않는다. 시간 제한 때 후보 해·목적 상하한·gap·종료 상태를 함께 읽는다. [SciPy milp](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html)

큰 상수 `M`은 변수의 실제 상한에서 도출한다. 지나치게 크면 수치 문제와 약한 완화가 생기고 작으면 유효 해를 잘라낸다. 가능하면 실제 라이브러리가 지원하는 조건부 제약을 검토한다. 정수 허용 오차가 있는 결과는 독립 검증기에서 원래 단위와 허용 기준으로 검사한다.

### CP-SAT·제약계획

정수 선택, 조건부 논리, 배타적인 시간 구간, 인원 수처럼 조합 조건이 많을 때 검토한다. “이 작업을 선택하면 이 시간 구간이 존재한다”는 관계를 누락하지 않는다. CP-SAT은 정수 계수 표현을 사용하므로 소수 시간·금액의 단위 변환과 최대 합을 검토한다. 초 단위를 분으로 올림하면 도착 마감 가능성이 바뀔 수 있다. [CP-SAT 공식 문서](https://developers.google.com/optimization/cp/cp_solver)

### SAT·2-SAT·정확 덮기

참/거짓의 조합 가능성만 필요하면 SAT를, 모든 절이 두 리터럴인 구조이면 2-SAT를 검토한다. 2-SAT는 함의 그래프의 강한 연결 요소로 `O(V+E)`에 판정할 수 있지만 일반 SAT 조건을 억지로 두 항으로 쪼개면 의미가 달라질 수 있다. 정확 덮기는 각 요구를 정확히 한 번 덮는 후보 집합을 선택하는 구조로, 작은 문제의 백트래킹·Algorithm X를 검토한다. 비용·용량·시간 조건이 더해지면 함께 표현하고 검사해야 한다.

## 집합과 자원 선택

### 집합 덮기·집합 분할·집합 포장

후보 하나가 여러 대상을 처리할 때 등장한다. 덮기는 적어도 한 번, 분할은 정확히 한 번, 포장은 겹침 없이 일부를 선택한다. 겹치는 배정을 허용하는지에 따라 식이 달라진다. 후보별 비용 대비 새로 처리하는 수를 보는 탐욕법은 설명 가능한 기준선이지만 정답 보장은 문제 조건에 의존한다. 유한 후보의 정수 모형을 풀어도 만들지 않은 후보까지 포함한 전역 최적은 아니다. [Cornell 알고리즘 강의의 근사·집합 덮기 범위](https://www.cs.cornell.edu/courses/cs4820/2025fa/lectures/)

검산에서는 모든 대상의 덮인 횟수를 직접 센다. 0인 대상, 두 번 배정된 대상, 선택되지 않은 후보가 처리했다고 표시된 대상을 분리한다. 후보 추가·삭제 효과와 정책 완화 효과를 알고리즘 개선 효과와 나누어 기록한다.

### 시설 입지·p-median·p-center

시설 개방 비용과 대상 접근 비용을 함께 고려하면 시설 입지를, 시설 수를 고정하고 총 접근 비용을 줄이면 p-median을, 최악의 접근 비용을 줄이면 p-center를 검토한다. 평균 거리 감소와 최악 대상의 부담 감소는 다른 목적이다. 시설별 용량·개방 가능 위치·금지 연결을 넣어야 실제 배정이 된다. 군집 중심을 시설 위치로 바로 쓰면 설치 불가능한 곳을 선택할 수 있으므로 후보 위치 제약을 확인한다.

### Bin packing·다중 배낭·일반화 배정

모든 항목을 용량 제한 자원에 넣으며 자원 수를 줄이는 bin packing과, 제한 자원 안에서 가치 있는 일부를 고르는 배낭은 목적이 다르다. First Fit·Best Fit·감소순 정렬 버전은 빠른 기준선이며, 단순 구현은 항목 수 `n`, 사용 자원 수 `b`에 대해 `O(nb)`가 들 수 있다. 큰 항목 우선이 항상 최적은 아니다. [OR-Tools bin packing 설명](https://developers.google.com/optimization/pack/bin_packing)

항목 크기가 자원별로 달라지는 일반화 배정, 여러 차원의 용량, 같은 자원에 두면 안 되는 충돌은 따로 모형화한다. 어떤 항목이 모든 자원의 용량보다 큰지 먼저 확인하고, 자원을 무한히 추가할 수 있다는 가정을 실제 보유량과 구분한다.

## 목표를 정하는 방법

### 사전식 우선순위

필수 조건은 후보의 유효성을 가르는 제약으로 먼저 적용한다. 전원 처리가 필수이면 일부를 제외한 결과는 비용이 낮아도 최종 유효 후보가 아니다. 그 제약을 통과한 후보 안에서 비용 → 편의처럼 상위 운영 목표를 하위 개선으로 교환할 수 없다면 단계별로 최적화한다. 상위 단계의 최적성을 증명하지 못했다면 “현재 찾은 상위 값 고정”으로 표현한다.

별도 허용된 부분배정 실험에서는 처리 수 최대화 → 같은 처리 수에서 비용 최소화로 원인과 개선 방향을 조사할 수 있다. 이 실험을 전원 처리 의무를 만족한 서비스 결과로 승격하지 않는다. 너무 작은 미처리 벌점으로 대상 한 명을 제외하고 비용을 낮추는 결과가 나오지 않게 한다.

### 가중합과 파레토 비교

가중합은 서로 다른 목표를 교환해도 된다는 정책이다. 시간·금액·대상 수를 한 값에 섞을 때 단위와 가중치 의미를 설명한다. 근거가 없으면 몇 가지 비지배 후보의 실제 수치를 보여주고 중요한 절충 하나를 묻는다. 정규화 기준을 바꾸면 같은 가중치의 뜻도 달라진다. 작은 가중치 변화에 선택이 급변하는지 확인한다.

### 강건·시나리오 모형

불확실한 수요·처리시간에 대해 여러 시나리오를 비교하거나 허용 범위의 최악을 다룬다. 모든 가능한 상황을 보장하는 모형과 추출한 몇 시나리오를 통과한 실험을 구분한다. 보수성 증가로 비용·미처리가 늘 수 있으므로 시나리오의 출처와 범위를 기록한다. 확률을 모르면 임의 확률로 기대 비용을 공식 수치처럼 만들지 않는다.

## 해석과 독립 검증

`최적`, `유효한 후보`, `불가능 증명`, `시간 제한으로 미발견`, `모형 오류`를 따로 표시한다. CP-SAT의 `UNKNOWN`은 불가능을 뜻하지 않는다. 이 구별을 API와 화면까지 유지한다. 이전 유효 결과가 있으면 새 시도가 끝나기 전에 덮어쓰지 말고 현재 입력·설정에서 여전히 유효한지도 검사한다.

솔버와 별도 경로로 원래 입력의 대상 포함, 용량, 시간, 연결, 선택 여부, 정책 예외를 재계산한다. 작은 사례는 완전탐색과 비교한다. 정수 제한을 풀어 얻은 하한, 총량 기반 하한, 강한 제약을 뺀 완화의 값으로 결과 품질을 설명할 수 있지만 방향을 확인한다. 최소화 문제에서 유효 결과는 상한, 완화된 문제의 최적값은 하한이다.

복잡한 모형을 큰 데이터에 넣기 전에 빈 입력, 0 용량, 불가능한 단일 대상, 동률, 한계값, 설정 변경을 확인한다. 탐색 예산은 후보 생성·입력 변환·독립 검사·저장까지 포함해 측정한다. 알고리즘 비교 시 같은 입력·설정·정책을 사용한다.

## 사용자에게 설명할 선택

“평균 부담을 줄일까요, 가장 불리한 대상부터 개선할까요?”, “추가 자원을 쓰면 비용이 얼마 늘어도 괜찮을까요?”, “현재 선호를 어느 범위까지 자동 완화할까요?”처럼 운영상의 결과를 묻는다. 일반 구현 선택과 이미 위임된 조정은 계속 진행하고, 확정되지 않은 정책을 기본값으로 몰래 강제하지 않는다.
