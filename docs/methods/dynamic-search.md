# 동적계획·선택·정확 탐색

선택한 이력이 앞으로의 가능성을 바꾸는 문제에서 사용한다. 상태에 미래 판단에 필요한 정보가 빠지면 빠르게 계산해도 틀린다. `n`은 항목 수, `C`는 정수 용량/합 범위, `S`는 실제 상태 수, `T`는 상태당 전이 수다. 최적값만 필요한지 선택한 항목·순서까지 복원해야 하는지도 먼저 정한다.

## D01 — 완전탐색과 독립 기준 해

- **목적:** 작은 입력의 모든 후보를 검사해 정확한 최선과 구현 반례를 찾는다. 부분집합 `2^n`, 순열 `n!`, 조합 곱은 빠르게 커진다.
- **사용:** 본 서비스의 큰 입력을 풀기 어렵더라도 작은 축소 문제에서 후보 생성기와 별도로 검사기를 만든다. 후보와 검산이 같은 잘못된 제약 함수를 공유하면 독립성이 약해진다.
- **반례·한계:** 일부 후보만 열거하고 전역 최적이라고 말하지 않는다. 입력 규모·상태 수·시간 제한을 적용해 중단한 경우 `검산 미완료`로 표시한다.
- **검산:** 검사기 자체도 손으로 계산한 0·1·2항목 사례와 교차 확인한다. 축소 과정에서 원래의 결합 제약이 사라지지 않았는지 밝힌다.

## D02 — 백트래킹·제약 전파·대칭 제거

- **목적:** 부분 선택을 확장하면서 이미 위반한 후보를 자른다. 각 선택지 수가 `b`, 깊이가 `d`면 최악은 `O(b^d)` 수준이며 가지치기가 최악 지수를 없애지는 않는다.
- **사용:** 선택지가 적은 대상을 먼저 처리하고, 이미 소모한 용량·금지 조합을 즉시 확인한다. 서로 같은 자원의 순서를 바꾸기만 한 중복은 실제 동등성이 증명될 때 제거한다.
- **반례:** 현재 비용이 크다는 이유로 미래의 음수 비용 가능성을 무시하고 자르면 정답을 잃는다. 대상 ID만 다를 뿐 같다고 보고 대칭을 제거하면 개별 조건을 잃을 수 있다.
- **검산:** 가지치기 없는 작은 열거와 결과를 비교한다. 상태 변경을 되돌리는 코드는 실패·예외 경로에서도 원상 복구되는지 확인한다.

## D03 — 분기 한정 / Branch and Bound

- **목적:** 현재 최선의 유효 해와 각 부분 문제의 낙관적인 하한/상한으로 더 좋아질 수 없는 분기를 자른다.
- **조건:** 최소화라면 하한이 실제 가능한 최솟값보다 커서는 안 된다. 유효 해의 비용이 상한이 된다. 종료 시 탐색이 끝나지 않았다면 최선 해와 bound를 구분해 보고한다.
- **반례:** 휴리스틱 결과를 하한으로 사용하면 더 나은 해를 포함한 분기를 제거할 수 있다. 후보 생성 제한이 있으면 그 후보 집합 밖의 최적성은 별도다.
- **검산·연결:** 작은 전체 열거와 bound의 방향을 확인한다. 실행시간이 부족해도 마지막 유효 해를 보존하되 최적성 여부를 따로 기록한다.

## D04 — 메모이제이션·상태 DP

- **목적:** 같은 부분 문제를 반복 계산하지 않는다. 기본 계산량은 `O(S×T)`, 메모리는 보관한 상태·복원 정보에 따른다.
- **상태 설계:** “다음으로 처리할 위치, 남은 용량”처럼 이후 선택 가능성과 비용을 결정하는 정보를 담는다. 과거 전체를 담을 필요는 없지만 필요한 자격·마지막 위치·사용 이력을 빠뜨리면 안 된다.
- **반례:** 현재 남은 총좌석이 같아도 자원별 자격이 다르면 같은 상태가 아니다. 캐시 키에서 설정 버전을 빼면 새 정원에서 예전 답이 재사용된다.
- **검산:** 상태별 작은 완전탐색과 비교하고, 순환 전이가 있으면 단순 재귀 캐시로 해결되는 DAG인지 확인한다. [MIT 강의 자료](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/pages/lecture-notes/)를 상태·전이·순서 설명의 참고로 삼을 수 있다.

## D05 — 0/1·무제한·제한 개수 배낭

- **목적:** 한 자원의 정수 용량 안에서 항목 가치 합을 최대화한다. 기본 0/1 배낭은 `O(nC)` 시간, 값만 구하면 `O(C)` 저장으로 줄일 수 있다.
- **조건:** 0/1과 무제한 선택은 갱신 방향이 다르다. 제한 개수는 수량을 반영한 전이나 묶음 분해 등이 필요하다. 선택 목록 복원 시 1차원 값 배열만 덮어쓰면 이력이 꼬일 수 있다.
- **반례:** 가치/무게 비율로 먼저 고르는 방법은 분할 불가능한 0/1 배낭의 일반 정답이 아니다. 실수 무게를 임의 반올림하면 허용·불허가 달라진다.
- **규모·검산:** `O(nC)`는 입력 숫자의 비트 수 기준 다항 시간이 아닌 의사다항 시간이다. 작은 부분집합 열거, 용량 0·무게 0·음수 금지 정책·중복 항목을 검사한다. [배낭을 포함한 DP 강의](https://ocw.tudelft.nl/course-lectures/5-dynamic-programming/).

## D06 — 부분합·동전·카운팅 DP

- **목적:** 합을 만들 수 있는지, 최소 몇 개가 필요한지, 몇 가지 방법인지 계산한다. 상태 범위 `C`에 대한 기본 DP는 흔히 `O(nC)`.
- **조건:** 순서가 다른 선택을 다른 방법으로 셀지, 같은 값의 개별 항목을 구분할지 정한다. 반복문의 순서가 순열/조합과 재사용 가능 여부를 바꾼다.
- **반례:** 동전 `1,3,4`로 6을 만들 때 큰 값 우선은 3개지만 `3+3`은 2개다. 음수 항목이 있으면 0부터 목표까지의 배열로 충분하지 않을 수 있다.
- **검산:** 작은 목록의 모든 선택을 생성해 존재·개수·최솟값을 각각 비교한다. [MIT 부분합 변형 자료](https://live.ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/e88f4499b351ab82ebf07c4de2859272_MIT6_006S20_r18.pdf)는 상태 범위를 실제 값에 맞춰 잡는 사례를 제공한다.

## D07 — LIS·LCS·편집 거리

- **LIS:** 수열에서 순서를 지킨 증가 부분수열. 직접 DP `O(n²)`, 최소 끝값과 이분 탐색으로 길이는 `O(n log n)`. 엄격 증가와 비감소에 따라 경계가 다르고 끝값 배열 자체가 해의 원소 목록은 아니다.
- **LCS:** 두 수열 길이 `n,m`의 최장 공통 부분수열은 기본 `O(nm)`. 순서를 보존하지만 연속일 필요는 없다. 공통 부분문자열과 구분한다.
- **편집 거리:** 허용한 삽입·삭제·치환 비용 아래 기본 DP `O(nm)`. 문자 단위·전치 허용·가중 비용을 바꾸면 문제가 달라진다. 문자열 적용은 [문자열 자료](strings.md)를 본다.
- **검산:** 짧은 부분수열/편집을 열거해 대조하고, 해 복원과 최소 비용 값이 일치하는지 확인한다. 메모리 절감이 복원 기능을 잃지 않는지 검토한다.

## D08 — DAG·트리·구간 DP

- **DAG DP:** 위상 순서로 선행 결과를 결합한다. 각 간선을 한 번 처리하는 상태면 `O(V+E)`다. 자원 제약이 추가되면 상태 수가 증가한다.
- **트리 DP:** 자식 서브트리 결과를 부모에서 결합한다. 단순 선택/비선택은 선형일 수 있지만 용량별 자식 병합은 더 비싸다. 루트 간 답을 재사용하는 rerooting은 결합·제외 연산을 정확히 정의해야 한다.
- **구간 DP:** `[l,r)`를 여러 분할점으로 나누는 구조. 구간 `O(n²)` × 분할 `O(n)`인 기본형은 `O(n³)`다. 양끝 관계가 중요한 병합·구문·순서 문제에 쓴다.
- **반례·검산:** 트리 바깥의 추가 연결, 구간 밖 상태 의존을 누락하지 않는다. 작은 전체 분할·선택과 비교한다.

## D09 — 부분집합 DP·비트마스크

- **목적:** 작은 대상 집합에서 사용한 대상과 마지막 상태를 기억한다. 경로형 `dp[mask,last]`는 흔히 시간 `O(n²2^n)`, 저장 `O(n2^n)`.
- **조건:** 정확한 상태 수와 각 상태의 Python 객체 비용부터 추산한다. 비트마스크가 짧게 보인다는 이유로 큰 `n`에 쓰지 않는다.
- **반례:** 같은 `mask,last`라도 남은 시간·자원·개별 조건이 다르면 추가 상태가 필요하다. 단순 비용 합만 최적화한 뒤 시간을 검사하면 유효 해를 놓칠 수 있다.
- **검산:** 작은 순열 열거와 비교한다. 전원 방문과 일부 선택의 종료 상태를 구분한다. SOS DP는 부분집합 합계를 `O(n2^n)`로 공유하는 별도 조건부 기법이며 일반 최적화 전이를 모두 가속하지 않는다.

## D10 — Meet-in-the-middle

- **목적:** 항목을 반으로 나눠 양쪽 선택 결과를 결합한다. 부분합이면 각 절반 `2^(n/2)`개 결과를 만들고 정렬·탐색한다. 단순 정렬 구현은 시간에 추가 `n` 계수가 붙고 저장도 지수적이다.
- **조건:** 양쪽 선택의 관계를 합·정렬·호환 조건으로 결합할 수 있어야 한다. 같은 합이 여러 번 생기면 존재·개수·복원에 맞춰 정보를 유지한다.
- **반례:** 양쪽 항목 사이의 복잡한 쌍 제약을 부분합 하나로 요약하면 불법 조합이 섞인다.
- **검산:** 작은 전체 부분집합과 비교한다. [MIT의 분할·정렬 결합 설명](https://people.csail.mit.edu/virgi/6.1420/lecture2.pdf)을 참고하되 대상 문제의 결합 가능성을 따로 확인한다.

## D11 — 탐욕법과 교환 논증

- **목적:** 현재 가장 유리한 선택을 고정해 단순한 기준본을 빠르게 만든다. 정렬 중심이면 `O(n log n)`인 경우가 많지만 비용은 구현별이다.
- **보장:** 최적성을 말하려면 교환 논증·cut 속성·matroid 같은 해당 구조의 근거가 필요하다. 그렇지 않으면 휴리스틱으로 표시한다.
- **반례:** 선택지가 많은 대상을 가까운 자원에 먼저 배정해 선택지가 하나인 대상을 놓칠 수 있다. 국소적으로 큰 가치가 전체 최선과 같지 않다.
- **검산·연결:** 작은 정확 해와 비교하고, 순서를 바꾼 반례를 찾는다. 유효한 부분 결과도 보존해 재배정·허용된 정책 안의 회복 대상으로 쓰지만 전원 성공으로 표시하지 않는다.

## D12 — DP 최적화·파레토 상태 제거

- **검토 신호:** 올바른 기본 DP를 만들었고 실제 병목이 상태 수 또는 전이 수에 있다.
- **조건부 후보:** 전이 비용의 단조성이 증명되면 divide-and-conquer 최적화, 더 강한 부등식 조건이 맞으면 Knuth 최적화, 선형식의 최솟값 질의면 convex hull trick/Li Chao tree, 자원과 비용이 여러 축이면 지배 상태 제거를 검토한다.
- **반례:** 잘 되는 예시 몇 개만 보고 최적 분할점이 단조라고 가정하지 않는다. 현재 비용과 자원이 더 좋아도 앞으로의 선택 가능성이 다르면 지배 상태가 아니다.
- **검산:** 작은 무최적화 DP와 무작위·경계 입력에서 대조하고 전제의 근거를 남긴다. 이런 기법은 적용 조건이 확인됐을 때 추가 조사하는 선택지이며 기본 구현에 일괄 포함하지 않는다.

## D13 — 게임 상태·minimax·알파베타

- **적용:** 명시된 차례·합법 행동·종료 효용이 있는 대립 선택. minimax는 분기 `b`, 깊이 `d`에서 최악 `O(b^d)`. 알파베타는 같은 minimax 값을 유지하며 불필요한 분기를 줄이지만 최악 비용은 그대로다.
- **한계:** 협력적 자원 배분을 상대가 방해하는 게임으로 바꾸지 않는다. 확률 행동은 기대값 모형, 숨은 정보는 관측 모형이 별도로 필요하다.
- **검산:** 작은 전체 게임 트리와 비교하고 차례·동률·무승부를 검사한다. Nim/Grundy는 유한 impartial 정상 종료 게임 등 전제가 맞을 때만 별도로 검토한다.

## D14 — Digit DP·경계 프로필 DP

- **Digit DP:** 상한 이하 정수의 자릿수 조건을 세거나 최적화한다. 자리 위치·상한과의 일치 여부·앞선 0 처리·필요한 누적 상태를 둔다. 자리 수와 상태 수, 자릿값 수의 곱이 계산량을 결정한다. 선행 0을 실제 숫자로 세거나 0 자체의 포함 여부를 놓치지 않는다.
- **프로필 DP:** 좁은 격자·띠 구조를 한 열씩 처리하며 경계의 연결/사용 상태만 보존한다. 길이에 선형일 수 있지만 폭에 대해 상태 수가 지수적으로 커질 수 있다. 경계 밖 연결 정보가 이후 선택을 바꾸면 상태에 포함해야 한다.
- **검산:** 작은 정수 범위나 작은 격자를 전수 열거한다. 이 방법들은 일반 표를 입력받는다는 이유만으로 적용하지 않고, 자릿수/좁은 경계 구조가 실제로 있을 때 선택한다.

## D15 — 분할 정복과 부분 문제 결합

- **목적:** 문제를 나눠 각 부분을 풀고 합친다. merge sort·공간 분할·일부 DP 최적화처럼 결합 비용과 분할 균형이 전체 시간을 결정한다.
- **조건:** `T(n)=aT(n/b)+f(n)` 같은 형태가 맞을 때 점화식으로 비용을 분석한다. 서로 다른 크기로 나뉘거나 공유 상태가 있으면 같은 공식을 기계적으로 쓰지 않는다.
- **반례:** 두 지역의 배정을 따로 최적화하면 공유 자원과 경계 대상 때문에 전체 최선·실행 가능성을 놓칠 수 있다. 부분 문제 독립성과 결합 시 전역 검증을 확인한다.
- **검산·연결:** 작은 전체 직접 풀이와 비교한다. 병렬 워커로 분할하는 구현 방식과 수학적으로 문제가 분리된다는 주장은 구분한다.
