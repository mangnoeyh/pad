# 연결 관계와 경로

노드가 무엇이고 간선이 무엇을 허용하는지 먼저 정한다. `V`는 노드 수, `E`는 간선 수다. 방향·가중치 단위·다중 간선·자기 루프·금지 연결·없는 값의 의미를 저장한다. 비용 누락을 0이나 1로 채우지 않는다. 라이브러리 기본값이 그렇게 처리할 수 있으므로 명시적으로 검증한다. [NetworkX 최단경로 문서](https://networkx.org/documentation/stable/reference/algorithms/shortest_paths.html)는 무가중·가중·방향에 따른 API 선택을 설명한다.

## 빠른 선택

| 질문 | 후보 | 판단 경계 |
| --- | --- | --- |
| 연결돼 있는가, 몇 번 이동하는가 | BFS·DFS·연결 요소 | 이동 비용이 모두 같은가 |
| 비용을 합한 가장 싼 경로인가 | Dijkstra·0-1 BFS·Bellman–Ford·DAG DP | 비용 부호·구조에 맞춰 선택 |
| 선행 작업 뒤에 무엇을 실행할 수 있나 | 위상 정렬 | 순환 의존성은 별도 오류 |
| 모든 지점을 적은 연결비로 잇나 | 최소 신장 트리 | 각 쌍의 최단경로·순회와 다름 |
| 단일 장애로 나뉘는 곳은 | 단절점·브리지 | 무방향·다중 간선 처리 확인 |
| 좌석·작업을 연결에 맞춰 배정하나 | 매칭·흐름 | 경로 선택과 결합되면 전체 모형 검증 |

## G01 — BFS와 다중 시작점 BFS

- **적용:** 무가중 또는 모든 간선 비용이 같은 그래프의 최소 간선 수. 여러 공급점 중 가장 가까운 공급점은 시작점을 한 큐에 넣는다. 시간·공간 `O(V+E)` 범위.
- **보장:** 큐에 발견한 노드를 중복 등록하지 않도록 거리/방문 상태를 관리하면 최소 단계 수를 구한다.
- **반례:** 직접 간선 비용 10, 두 단계 경로 비용 2라면 단계 수가 적은 경로가 최소 비용은 아니다.
- **검산·연결:** 작은 전체 거리표와 비교하고 부모 링크로 경로를 복원한다. 도달 불가를 0거리로 쓰지 않는다. 입력·정책별 허용 간선이 바뀌면 거리 캐시도 바뀐다.

## G02 — DFS·연결 요소·순환 탐지

- **적용:** 도달 가능성, 무방향 연결 성분, 탐색 트리, 구조 점검. `O(V+E)`.
- **조건:** 방향 그래프 순환 탐지는 현재 탐색 경로와 완료된 노드를 구분한다. 무방향에서는 부모 간선과 되돌아가는 간선을 구별한다.
- **반례:** DFS가 처음 찾은 경로를 최단경로라고 하지 않는다. 무방향의 연결과 방향의 서로 도달 가능성은 다르다.
- **검산·연결:** 긴 사슬은 재귀 깊이를 초과할 수 있으므로 반복 스택을 고려한다. 모든 노드가 간선 목록에 등장하지 않아도 고립 노드를 남긴다.

## G03 — 위상 정렬과 DAG 동적계획

- **적용:** 선행 작업, 의존 관계, 비순환 단계 비용. Kahn의 진입차수 큐 또는 DFS 완료순서로 `O(V+E)`.
- **보장:** 모든 노드가 처리됐는지 검사해야 유효한 순서다. 이 순서에서 최단/최장 경로·누적량을 갱신할 수 있다. DAG 최단경로는 음수 간선도 순환이 없으면 다룰 수 있다.
- **반례:** 위상 순서는 자원 수와 실행시간을 포함한 최적 스케줄이 아니다. 순환을 무시하고 일부 노드만 반환하면 작업 누락이 생긴다.
- **검산·연결:** 모든 간선의 앞뒤 순서를 독립 검사한다. 준비된 작업 중 동률 정책이 필요하면 힙으로 정하지만 비용은 증가한다. [DAG 공식 문서](https://networkx.org/documentation/stable/reference/algorithms/dag.html)는 입력이 DAG인지 호출자가 확인해야 하는 API가 있음을 명시한다.

## G04 — Dijkstra

- **적용:** 고정된 비음수 간선 비용의 단일 시작점 최단경로. 이진 힙의 일반 표현은 `O((V+E) log V)`; 중복 항목을 넣는 구현은 힙 크기와 `log E`도 고려한다.
- **보장:** 꺼낸 오래된 거리 항목을 건너뛰고 완화한다. 목표 하나만 필요하면 해당 노드의 최단거리가 확정될 때 멈출 수 있다.
- **반례:** 음수 비용, 도착시각에 따라 달라지는 비용, 경로에 따라 달라지는 탑승 제약을 단순 노드 거리 하나로 표현하면 잘못될 수 있다.
- **검산·연결:** 작은 그래프는 Bellman–Ford나 Floyd–Warshall과 비교한다. 반환 경로의 방향·간선·총비용을 다시 계산한다. 실제 지도 경로가 있어도 시간은 입력 속도와 연결 가정에 따른 추정일 수 있다.

## G05 — 0-1 BFS

- **적용:** 비용이 정확히 0 또는 1인 그래프. 비용 0 간선은 덱 앞, 비용 1 간선은 뒤로 갱신해 `O(V+E)`에 처리한다.
- **반례:** 정수 비용이라는 이유만으로 2·3·10을 같은 방식으로 넣지 않는다. 0비용 순환에서도 거리 개선일 때만 처리한다.
- **검산:** 작은 비음수 그래프에서 Dijkstra와 비교한다. 비용 집합을 읽기 단계에서 검사한다.

## G06 — Bellman–Ford와 음수 순환

- **적용:** 음수 간선이 허용된 최단경로와 시작점에서 도달 가능한 음수 순환 탐지. 일반 시간 `O(VE)`, 거리 저장 `O(V)`.
- **보장 경계:** 음수 순환이 존재해도 해당 시작점에서 도달 불가하거나 목표에 도달하지 못하면 특정 질의의 의미는 다르다. 영향받는 노드를 따로 표시한다.
- **반례:** 추가 완화가 발생했다는 이유로 모든 목표를 무효 처리하지 않는다. 도달 불가 거리의 sentinel에 음수값을 더해 도달했다고 만들지 않는다.
- **검산:** 직접 경로 열거가 가능한 작은 사례와 음수 순환의 도달성 사례를 검사한다. 큐 기반 변형이 항상 빠르다고 가정하지 않는다.

## G07 — Floyd–Warshall·Johnson·반복 시작점 탐색

- **적용:** 여러 출발·도착쌍. Floyd–Warshall은 `O(V³)` 시간·`O(V²)` 공간으로 작은 밀집 그래프에 적합하다. 희소한 큰 그래프는 필요한 출발점만 Dijkstra하거나, 음수 간선이 있으나 음수 순환이 없을 때 Johnson을 검토한다.
- **한계:** 전 노드 쌍의 저장은 작은 간선 수와 무관하게 커진다. Johnson의 재가중 후 원래 비용 복원이 필요하다.
- **검산·연결:** 일부 출발점의 독립 단일 시작점 결과와 비교한다. 방향별 거리를 대칭으로 복사하지 않는다. 자료 버전별 사전 계산을 유지한다.

## G08 — A*와 양방향 탐색

- **적용:** 특정 시작·목표 경로를 반복 찾으며 유효한 휴리스틱이 있거나 양끝 탐색이 가능한 경우.
- **조건:** A*의 최적성은 휴리스틱의 과대평가 여부와 닫힌 노드 재처리 규칙에 의존한다. 일관된 휴리스틱 또는 적절한 재개방 처리를 사용한다. 양방향 탐색은 두 전선이 처음 만났다고 무조건 종료하지 않는다.
- **반례:** 거리를 시간 하한으로 바꿀 때 속도 상한을 잘못 두면 추정값이 실제 최단시간보다 커질 수 있다. 방향 그래프의 역방향 탐색은 역간선 그래프가 필요하다.
- **검산:** Dijkstra와 같은 최단비용인지 비교한다. 좋은 휴리스틱이 없으면 복잡도·성능 개선을 보장하지 않는다.

## G09 — Union–Find / DSU

- **적용:** 무방향 연결을 합치며 같은 집합인지 질의. 크기/랭크 합병과 경로 압축을 쓰면 연산당 상각 `O(α(V))`, 저장 `O(V)`.
- **반례:** 일반 DSU는 간선 삭제나 방향 도달성을 처리하지 못한다. 연결되어 있다는 정보로 경로나 연결 비용을 복원할 수 없다.
- **검산·연결:** 작은 그래프를 매번 BFS한 연결 결과와 비교한다. ID와 내부 인덱스의 대응을 보존한다. 롤백 DSU는 보통 경로 압축을 생략하고 변경 이력을 저장하므로 다른 성능·구현 조건을 가진다.

## G10 — 최소 신장 트리: Kruskal·Prim

- **적용:** 무방향 가중 그래프에서 모든 지점을 연결하는 총 간선 비용 최소화. Kruskal은 정렬 중심 `O(E log E)`, 이진 힙 Prim은 `O(E log V)` 수준.
- **보장 경계:** 그래프가 끊겨 있으면 신장 숲이며 모든 지점 연결에 성공한 것이 아니다. 음수 간선은 MST 자체를 막지 않는다.
- **반례:** 최소 신장 트리는 출발지별 최단거리나 방문 순서를 최소화하지 않는다. 방향 연결 문제에 그대로 적용하지 않는다.
- **검산:** 연결성·간선 수·순환 없음·총비용을 검사한다. 작은 사례는 간선 부분집합을 열거해 비교한다. 방법과 cut/cycle 관점은 [Princeton 저자 교재](https://algs4.cs.princeton.edu/43mst/)에서 확인할 수 있다.

## G11 — 강한 연결 요소: Tarjan·Kosaraju

- **적용:** 방향 그래프에서 서로 왕복 가능한 묶음과 순환 의존성을 축약. 인접 리스트에서 `O(V+E)`.
- **연결:** 성분을 하나의 노드로 축약하면 DAG가 되지만 성분 내부 제약이 해결된 것은 아니다. 2-SAT의 모순 판정 등 다른 모형의 일부로 쓸 수 있다.
- **반례·검산:** 무방향 성분 검사로 대신하지 않는다. 작은 그래프의 모든 노드쌍 도달성을 구해 같은 성분인지 대조한다.

## G12 — 단절점·브리지·이분 그래프

- **적용:** 노드/간선 한 개 장애에 대한 연결 취약성, 두 종류로 충돌 없이 분류 가능 여부. DFS low-link와 BFS/DFS 색칠은 각 `O(V+E)`.
- **반례:** 평행 간선이 있으면 부모 노드만 비교하는 브리지 코드가 틀릴 수 있어 간선 ID로 구분한다. 이분 그래프 가능성은 균등 배정·정원 충족을 보장하지 않는다.
- **검산:** 작은 무방향 그래프에서 간선/노드를 하나씩 제거한 연결성, 모든 색 배치를 열거한 결과와 비교한다. 자기 루프·홀수 순환을 포함한다.

## G13 — 트리 경로·LCA·트리 DP

- **적용:** 실제 구조가 트리일 때 조상·경로 합·서브트리 처리. binary lifting LCA는 전처리 `O(V log V)`, 질의 `O(log V)`. DFS 진입/종료순서로 서브트리를 구간으로 바꿀 수 있다.
- **반례:** 일반 그래프의 DFS 트리를 만들었다고 원래 모든 경로 정보를 보존하지는 않는다. 트리 DP는 부모 밖의 추가 간선이 있으면 상태가 부족할 수 있다.
- **검산:** 작은 트리에서 직접 부모를 올라가며 비교한다. 루트, 여러 연결 성분, 깊은 사슬, 루트 변경 의미를 확인한다. 갱신이 많은 경로 질의는 [HLD 선택 기준](ranges-and-time.md)을 본다.

## G14 — Euler 경로·Hamilton 경로·k개 경로

이름이 비슷하지만 목적이 다르다. Euler 경로는 모든 간선을 한 번씩 사용하며 연결성·차수 조건을 확인한 Hierholzer 구현은 `O(V+E)`다. Hamilton 경로는 각 노드를 한 번씩 방문하며 일반 그래프에서는 같은 선형 해법을 기대할 수 없다. 작은 경우 부분집합 DP나 제한 탐색을 검토한다. k개 최단 경로는 순환 허용 walk인지 단순 경로인지 먼저 정하고, 같은 비용의 서로 다른 경로·중복 반환 정책을 명시한다.

## G15 — 함수형 그래프·점프 테이블

- **적용:** 각 노드가 다음 노드 하나를 가리키는 반복 상태 전이, k번 뒤의 상태 조회. 체인과 순환을 분해하거나 binary lifting으로 `2^j`번 뒤를 저장한다. 최대 점프 `K`에서 전처리·공간 `O(V log K)`, 질의 `O(log K)`.
- **조건:** 전이가 고정된 함수여야 한다. 종료를 별도 sentinel로 둘지 흡수 상태로 둘지 정한다. 순환이 오류인지 정상 반복인지 업무 의미를 확인한다.
- **반례:** 시간이 지나며 설정에 따라 다음 상태가 바뀌는데 옛 점프표를 쓰면 틀린다. 한 간선의 변경이 그 노드 행에만 영향을 주는 것도 아니다.
- **검산:** 작은 k를 직접 전이한 값과 비교하고, 체인 끝·자기 루프·긴 주기·순환 진입 직전 사례를 포함한다.

## 그래프를 서비스와 연결할 때

노드 번호와 실제 ID, 경로의 원래 간선, 단위, 생성에 쓴 데이터·설정 버전을 결과와 함께 연결한다. “도달 불가”가 빠진 데이터 때문인지 실제 금지 연결 때문인지 구분한다. 일부 그래프만 대상으로 성공했으면 전체 성공으로 쓰지 않는다. 사용자가 결정할 것은 보통 알고리즘 이름보다 “가까움의 기준이 거리인가 시간인가”, “같은 비용에서 어떤 부담을 먼저 줄일 것인가”다.

범위 탐색에는 [저자 교재의 그래프 목차](https://cses.fi/book/book.pdf)를 참고했다. 개별 카드의 예시·검산과 서비스 적용 주의는 독자적으로 작성했으며 외부 구현을 복사하지 않았다. 라이브러리를 쓸 때는 설치된 버전의 반환값·누락 가중치·그래프 종류 지원을 확인한다.
