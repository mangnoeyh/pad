# 정수·조합·수치 계산

정확한 정수 계산, 나머지 계산, 실수 근사 계산을 구분한다. 결과의 단위와 허용 오차는 업무 요구에서 정하고 알고리즘 편의로 바꾸지 않는다. `n`은 항목/행렬 차원, `M`은 정수 상한, `b`는 지수 또는 비트 길이다. 큰 정수의 곱셈·나눗셈은 상수 시간이 아니므로 아래 산술 연산 수와 실제 시간을 구분한다.

## N01 — 정수·고정 소수·부동소수 선택

- **적용:** 개수·용량은 정수, 정해진 최소 단위의 금액·시간은 스케일한 정수, 연속 측정은 실수 등 실제 의미에 맞춘다.
- **반례:** 소수값을 정수로 반올림하면 제약 경계가 바뀔 수 있다. 이진 부동소수의 `0.1`을 이미 만든 뒤 Decimal로 바꿔도 처음 입력한 십진값이 복원되는 것은 아니다.
- **검산·연결:** 경계 직전·정각·직후, 합계 분모 0, NaN·무한대·음수의 허용 여부를 확인한다. 반올림은 입력/계산/표시 중 어느 단계인지 구분한다. [Decimal 공식 문서](https://docs.python.org/3/library/decimal.html)에서 정확도·반올림 context를 확인한다.

## N02 — Euclid GCD·LCM·확장 Euclid

- **적용:** 주기 정렬, 비율 약분, 정수 방정식. GCD는 나머지 연산 수 기준 `O(log min(a,b))` 수준이며 확장형은 `ax+by=gcd(a,b)` 계수도 구한다.
- **조건:** 0·음수 입력의 규약을 정한다. `lcm(a,b)`는 0 처리 후 `a/gcd(a,b)`를 먼저 곱하면 고정 폭 정수의 overflow 위험을 줄일 수 있지만 완전히 없애지는 않는다.
- **반례:** 두 주기가 같아지는 간격이 실제 일정 충돌을 모두 설명하지는 않는다. 시작 위상·허용 시간도 필요하다.
- **검산:** 작은 약수 열거와 항등식 대입으로 비교한다. Python의 정확한 API 동작은 [math 공식 문서](https://docs.python.org/3/library/math.html)를 확인한다.

## N03 — 빠른 거듭제곱·모듈러 역원

- **적용:** 지수가 큰 거듭제곱, 반복 변환, 나머지 연산. 제곱 반복은 `O(log b)`번 곱셈이며 매 단계 수 크기를 고려한다.
- **조건:** `a`의 mod `m` 역원은 `gcd(a,m)=1`일 때 존재한다. Fermat 기반 `a^(m-2)`는 소수 modulus 등 전제가 필요하다.
- **반례:** 모듈러 결과에서 일반 실수 나눗셈을 쓰거나 역원이 없는 수로 나누면 안 된다. 음수 지수·modulus 1·0을 호출부 계약에 맞춰 처리한다.
- **검산:** 작은 반복 곱셈과 비교하고 `(a×inverse) mod m`을 확인한다. 언어의 `pow` 인자와 실제 버전 지원을 확인한다.

## N04 — 소수 체·분해·소수성 검사

- **적용:** `M` 이하 소수 전체가 필요하면 Eratosthenes 체는 일반적으로 `O(M log log M)` 시간과 `O(M)` 저장. 구간만 필요하면 segmented sieve를 검토한다. 작은 단일 수 분해는 제곱근까지 시험 나눗셈이 단순하다.
- **조건:** Miller–Rabin 같은 방법은 사용한 base와 입력 범위에 따라 확률적 검사 또는 특정 범위에서 결정적 검사다. 보장 범위를 확인하지 않고 임의 큰 정수에 같은 주장을 하지 않는다.
- **반례:** 1을 소수로 처리하거나 제곱수의 마지막 약수를 빠뜨릴 수 있다. 큰 `M`에 전체 배열을 만들면 메모리 한계를 넘는다.
- **검산:** 작은 범위 전수 약수 검사, 소수 제곱, 곱, 경계값과 비교한다. 큰 수 인수분해가 필요할 때만 검증된 수치 패키지·별도 알고리즘을 조사한다.

## N05 — 중국인의 나머지 정리 / CRT

- **적용:** 여러 주기·나머지 조건의 공통 해 또는 여러 modulus에서 구한 결과 결합.
- **조건:** 서로소 modulus의 기본형과 서로소가 아닌 일반형을 구분한다. 일반형에서 두 나머지 차가 modulus들의 GCD로 나누어져야 호환된다. 결과는 결합 modulus에 따른 동치류다.
- **반례:** `x mod 2=0`과 `x mod 4=1`은 모순이다. 모든 입력을 무조건 서로소 공식에 넣지 않는다.
- **검산·연결:** 반환값을 모든 원래 합동식에 대입한다. 일정 문제라면 해가 허용 기간 안에 있는지도 추가 확인한다.

## N06 — 조합·카운팅·포함 배제

- **적용:** 선택·순서·조건별 경우의 수, 중복되는 집합의 크기. 작은 정확 정수는 이항계수·팩토리얼 등 표준 기능부터 검토한다.
- **조건:** 순열/조합, 동일 값의 구별, 복원추출 여부를 정한다. factorial 전처리와 모듈러 역원을 결합하려면 modulus와 인자의 조건이 맞아야 한다.
- **포함 배제:** 제약 집합 `k`개의 모든 교집합을 보는 기본 방식은 `O(2^k)`개 항을 다룬다. 중복 누락·부호·빈 집합을 검사한다.
- **반례·검산:** “경우의 수”를 전체 결과의 확률로 바꾸려면 경우들이 같은 확률인지 따로 확인한다. 작은 조합을 실제 생성해 집합 크기와 비교한다.

## N07 — 행렬 거듭제곱·선형 점화식

- **적용:** 같은 선형 상태 변환을 아주 많이 반복하는 경우. `d×d` 밀집 행렬의 기본 곱셈과 제곱 반복은 `O(d³ log b)` 산술 연산.
- **조건:** 변환이 단계마다 같거나 반복 구조를 명시할 수 있어야 한다. 열/행 벡터 convention과 곱셈 순서를 고정한다.
- **반례:** 경로 개수용 행렬의 거듭제곱은 정확히 k개 간선을 사용하는 walk를 셀 수 있지만 단순 경로 수와 같지 않다. 도중 조건에 따라 변환이 달라지면 고정 행렬 하나로 부족하다.
- **검산:** 작은 반복 횟수에서 단계별 계산과 비교한다. 정수 결과 크기·modulus·실수 오차 누적을 함께 관리한다.

## N08 — FFT·NTT·합성곱

- **적용:** 긴 배열의 합성곱, 다항식 곱, 신호의 주파수 표현. 길이를 `N`으로 맞춘 FFT 기반 합성곱은 보통 `O(N log N)` 수준.
- **조건:** 선형 합성곱은 길이 `n+m-1` 이상으로 zero padding해 원형 wraparound를 막는다. FFT는 실수 오차를, NTT는 적합한 modulus·원시근·지원 길이를 확인한다.
- **반례:** 큰 정수 계수를 부동소수 FFT 뒤 무조건 반올림하면 정확 정수 곱을 보장하지 못한다. 상관과 합성곱의 뒤집기·켤레 규칙이 다르다.
- **검산:** 작은 이중 반복 합성곱, 임펄스 입력, 음수·큰 계수와 비교한다. [SciPy FFT 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.fft.fft.html)는 입력 길이·정규화·출력 의미의 확인에 사용한다.

## N09 — 선형 시스템: LU·Cholesky·QR

- **적용:** `Ax=b` 형태의 연속 계산. 밀집 일반 분해는 차원 `n`에 대해 보통 `O(n³)`, 저장 `O(n²)`. 같은 `A`에 여러 `b`를 풀면 분해를 재사용할 수 있다.
- **조건:** 정방·비특이 행렬인지, 대칭 양의 정부호처럼 특수 구조가 있는지 확인한다. Cholesky는 해당 구조가 필요하다. 해를 구하려고 명시적 역행렬부터 만들 필요는 없다.
- **반례:** 잔차가 작아도 ill-conditioned 행렬에서는 해의 오차가 클 수 있다. NaN·무한대와 거의 종속인 행을 확인한다.
- **검산·연결:** `Ax-b`의 크기, 조건수·스케일, 알려진 해로 만든 입력을 확인한다. [SciPy solve 공식 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.solve.html)의 구조 가정과 실패 상태를 따른다.

## N10 — 최소제곱·SVD·희소 선형 계산

- **적용:** 과잉/부족 결정 선형 관계에서 잔차 최소화, 유효 rank·차원 진단. QR·SVD 등 실제 라이브러리의 검증된 분해를 우선 검토한다.
- **조건:** 단순 최소제곱은 좌표의 부호·정수·상하한 조건을 자동 만족하지 않는다. `AᵀA`를 직접 만들어 푸는 normal equations는 조건을 악화시킬 수 있다.
- **희소 계산:** 저장은 0이 아닌 항목 수에 맞춰 줄일 수 있지만 분해 중 fill-in이 생길 수 있다. CG 등 반복법은 행렬 구조·허용 오차·수렴 상태를 확인한다.
- **검산:** 잔차, rank, 특이값, 작은 밀집 기준을 비교한다. 모델 설명력과 수치적으로 방정식을 푼 정확성은 다른 주장이다. [SciPy lstsq 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.lstsq.html).

## N11 — 근 찾기·연속 최적화

- **근 찾기:** 연속 함수가 구간 양끝에서 다른 부호이면 이분법·Brent 방식으로 그 안의 근을 좁힐 수 있다. 종료는 절대·상대 오차와 반복 한도로 정한다. [brentq 공식 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.brentq.html).
- **Newton:** 미분과 초기점이 유용하면 빠를 수 있으나 발산·다른 근·미분 0에 주의한다. 성공 플래그와 잔차를 함께 확인한다.
- **최적화:** 함수의 근과 최솟값은 다른 문제다. 삼분 탐색/황금분할은 해당 구간의 unimodal 같은 조건을 확인한다. 미분 기반 국소 최적화에서 일반 비볼록 전역 최적성을 주장하지 않는다.
- **반례·검산:** 불연속 점의 부호 변화는 근을 보장하지 않는다. 작은 구간의 촘촘한 관찰은 진단용이며 일반 최적성 증명은 아니다. 엄격한 운영 제약을 허용 오차로 임의 완화하지 않는다.

## N12 — 온라인 합계·분산·확률 계산

- **적용:** 큰 스트림의 합·평균·분산을 전체 보관 없이 계산. 항목당 일정한 상태 갱신은 전체 `O(n)`·보조 공간 `O(1)`이 가능하다. 합은 정수 정확성 또는 보상 합산 등을 검토하고 분산은 수치적으로 안정된 갱신을 쓴다.
- **조건:** 표본/모집단 분산, 가중치, 결측 제외 분모, 병합된 집계의 표본 수를 유지한다. 독립 확률이 아닌 사건의 확률을 단순 곱하지 않는다.
- **반례:** 큰 값에 작은 편차가 있는 데이터에서 `평균 제곱-평균의 제곱`은 상쇄 오차가 클 수 있다. 배치 평균들을 동일 가중치로 평균내면 배치 크기가 다를 때 틀린다.
- **검산·연결:** 작은 고정소수/고정밀 기준과 비교하고 입력 순서를 바꿔 수치 민감도를 살핀다. 확률 추정·시뮬레이션 결과는 실제 관측치 및 확정 제약 충족과 구분한다.

## 조건부 심화 목록

정확한 요구가 생기면 선형 체·Möbius/약수 변환, Lucas 정리, NTT 다중 modulus 복원, 생성함수, 확률 DP, 수치 적분·보간 등을 추가 조사한다. 각 기법은 수의 범위·대수 구조·오차·확률 가정을 동반한다. 실제 필요한 계산이 작은 직접 합산이라면 이름이 복잡한 방법으로 교체하지 않는다.

표준 정수 연산과 반환 규약은 Python 공식 문서, 수치 API는 연결된 SciPy 공식 문서를 확인했다. 분류와 작은 실패 사례는 독자 작성이며 이 문서만으로 특정 패키지가 설치되었거나 모든 수치 방법이 검증됐다고 주장하지 않는다.
