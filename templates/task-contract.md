질문 ID별 상태(미확인·부분 답변·확정·보류), 실제 답과 출처, 남은 질문, 영향을 받는 작업을 기존 기록에 이어 남긴다. 답변이 없는 내용을 확인된 요구로 쓰지 않는다. 보류 중인 질문은 보류로 남긴다. 요구·수용 기준이 바뀌면 새 계약 ID와 변경 이유를 남기고 기준선·최선의 안정본을 다시 평가한다.

## 사용자 조건의 변경·예외가 필요한 경우

조건의 변경·예외는 위 기준본·전달 절차를 따르고 아래 근거를 같은 기록에 붙인다.

- 대상 조건 / 변경·예외 결정과 근거 / 유지할 문제 필수 및 나머지 조건:
- 예외 대상·기간·상황 / 발동 조건 / 영향을 받는 단위(개별 대상 또는 해당 대상을 포함한 묶음 등):
- 완화 정도·허용 범위 / 활성·보류·철회 / 재편성 시 적용 대상을 다시 판단하는 방법:
- 회복 후보와 원인 진단 / 예상·개별 확인·공동 실측을 구분한 효과:
- 전체 재검증: 미처리·새 누락·다른 대상 부담·예외 건수·정도·모든 필수 조건:

고정 명단 승인만 있으면 새 대상을 자동 포함하지 않는다. 일반 자동 선정 규칙을 승인한 경우에는 새 입력·설정에서 그 규칙에 맞는 대상과 묶음을 서비스가 선정하며 개별 승인을 다시 요구하지 않는다. 선정 근거와 적용 범위는 전체 재검증한다. 문제에서 허용한 운영 매개변수 변경은 필수 제약의 무단 완화와 구분하며, 계산·검증·출력 모두 현재 적용 값을 사용한다.
