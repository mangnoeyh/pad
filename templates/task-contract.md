## 관측 가능한 수용 조건

| 조건 ID | 입력·상황·행동 | 기대 결과 | 검증 명령·관찰 방법 | 역할·적용 범위·상태와 근거 |
| --- | --- | --- | --- | --- |
| | | | | |

기대 결과는 요구사항이나 독립된 근거에서 정한다. 검사 수나 선택 지표의 개선이 필수 조건 실패를 상쇄하지 않는다.

조건은 원문 필수·추가 강제·개선 목표·구현 가정을 구분하고, 적용 입력/후보와 활성·보류·철회 상태를 표시한다. 완화한 실험의 성공을 원래 조건의 충족으로 바꾸지 않는다.

- 새 강제 조건의 저비용 사전 점검: 필요조건 실패 / 필요조건 통과·해 미확인 / 유효한 해 검증
- 선택 지표·방향·비교 전제와 우선순위(해당하는 경우):
- 시작 상태 / 기준선과 실제 실행한 검사:
- 필수 회귀 검사:

## 사람의 판단 기록

| | | | |

질문 ID별 상태(미확인·부분 답변·확정·보류), 실제 답과 출처, 남은 질문, 영향을 받는 작업을 기존 기록에 이어 남긴다. 답변이 없는 내용을 확인된 요구로 쓰지 않는다. 보류 중인 질문은 보류로 남긴다. 요구·수용 기준이 바뀌면 새 계약 ID와 변경 이유를 남기고 기준선·최선의 안정본을 다시 평가한다.
