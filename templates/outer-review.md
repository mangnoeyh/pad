# 외부 판단 요청

선택 템플릿. 요구 의미·검증 기준·중요한 대안처럼 사람의 판단이 필요한 경우에 사용한다. 이미 명확한 작업 전체를 다시 승인받는 양식이 아니다.

- 계약 ID / 관련 반복:
- 판단이 필요한 한 질문:
- 지금 판단해야 하는 이유:
- 관련 지시·자료·실행 증거:
- 기대 결과와 근거:
- 실제 결과와 차이:
- 해 본 조치와 확인된 한계:
- 관련 조건의 출처 / 현재 집행 방식 / 변경 권한과 이미 위임된 범위:
- 회복을 검토할 사용자 조건·예외 대상·발동 조건·영향 단위·완화 범위:
- 유지할 문제 필수 조건 / 예상 구제 효과·부담과 실측 여부:

## 선택지

| 선택지 | 결과·수용 조건에 주는 영향 | 시간·범위·회귀 영향 | 아직 모르는 점 |
| --- | --- | --- | --- |
| | | | |

- 추천 결정과 이유:
- 필요한 사람의 답변(구체적으로):
- 답변 전 멈출 의존 작업:
- 답변 없이 계속할 수 있는 독립 작업:

## 결정 후

- 상태: 답변 대기 / 결정됨
- 실제 답변·결정자·확인 근거:
- 계약 변경 여부 / 새 계약 ID:
- 다시 확인할 기준선·필수 검사:
- 재개할 작업:

응답이 없거나 시간이 흘렀다는 이유로 동의로 처리하지 않는다. 결정이 필요한 작업은 기다리고 독립된 작업만 계속한다. 문제·환경에서 정한 필수 제약을 바꾸는 권한을 이 양식으로 만들 수는 없다. 사용자가 추가한 조건은 실제 결정이나 이미 위임된 범위에 따라 바꿀 수 있으며, 승인된 예외를 포함한 전체 결과를 재검증한다.
